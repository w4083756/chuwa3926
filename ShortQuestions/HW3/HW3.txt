The two main branches under Throwable are Error and Exception. For Error, we have StackOverflowError, OutIfMemoryError. For Exception, we have checked exception and Runtime Exception. 

Checked exception must be handled at compile time. The compiler enforced this rule. Unchecked exceptions extend RuntimeException and don’t require explicit handling. Check exception is the one the compiler forces you to handle. For checked exceptions, we have IOException and FileNotFoundException. For unchecked exceptions, we have NullPointerException and ArrayIndexOutOfBoundException.

In aggregation, the contained object can exist independently of the container, it’s a HAS-A weak relationship. In composition, the contained object’s lifecycle is tied to the container, it’s a PART-OF, strong relationship.
Aspect                                          Aggregation                              Composition
Relationship Type                         HAS-A(weak)                            PART-OF(strong)
Lifecycle                                       Independent                               Dependent
Object Creation Location             Outside the container                 Inside the container
UML Symbol                               Empty diamond                          Filled diamond
Example                                       Person-Country                          Car-Engine
